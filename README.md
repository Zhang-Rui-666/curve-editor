# 🎨 多曲线编辑器 - 每点可调斜率

一个功能强大的轻量级图形编辑器，支持**多条独立曲线**，每个控制点都可以**独立调整切线斜率**（通过拖拽粉色手柄）。纯原生实现，无任何依赖。

## ✨ 特性
- ✔️ 多条曲线管理（新建/删除/切换）
- ✔️ 单击画布添加控制点
- ✔️ 拖拽橙色控制点 → 移动位置
- ✔️ 拖拽粉色切线手柄 → 改变该点的切线方向与力度（斜率）
- ✔️ 实时渲染平滑曲线（Hermite → 三次贝塞尔）
- ✔️ 每条曲线拥有独立颜色
- ✔️ 保存画布为 PNG

## 🖥️ 快速开始
1. 下载所有文件至同一文件夹
2. 双击 `index.html` 在浏览器中打开
3. 开始绘制！

## 🎮 使用方法
- **新建曲线**：点击“➕ 新建”按钮
- **切换曲线**：通过下拉菜单选择
- **添加控制点**：在画布空白处单击
- **移动控制点**：按住橙色圆点拖拽
- **调整斜率**：按住粉色圆点（手柄末端）拖拽，可任意改变切线方向与长度（长度影响弯曲程度）
- **清空当前曲线点**：点击“🧹 清除点”
- **保存图片**：点击“📸 保存图片”

## 📐 曲线算法说明
使用**三次贝塞尔曲线**分段连接，每段连接两个相邻控制点。  
给定点 P0, P1 及其切线向量 T0, T1，贝塞尔控制点为：
C0 = P0
C1 = P0 + T0/3
C2 = P1 - T1/3
C3 = P1

text
这样曲线在 P0 处切线方向平行于 T0，在 P1 处平行于 T1。  
用户拖拽粉色手柄即改变 T0 和 T1 的向量，实现斜率独立调控。
