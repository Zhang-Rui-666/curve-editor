# 🎨 简易曲线编辑器 (Catmull-Rom 平滑曲线)

一个轻量级、无依赖的 Web 图形编辑器，用于绘制**通过所有控制点的平滑曲线**。支持拖拽控制点、实时预览、保存为图片。适合学习和快速原型设计。

## ✨ 特性
- 鼠标单击画布添加控制点
- 拖拽控制点任意调整位置
- 自动绘制 **Catmull-Rom 样条曲线**（完美通过每个控制点，视觉平滑）
- 清空所有控制点
- 导出画布为 PNG 图片
- 纯原生实现，不依赖任何第三方库
- 响应式界面，支持基本触摸操作

## 🖥️ 在线预览 / 本地运行

1. 下载本项目所有文件到同一文件夹。
2. 双击 `index.html` 在浏览器中打开即可。
